# Sealed Ink actor workspace (proposed next release)
Reconstruction from prior two-column character/NPC concept descriptions and the bundled design philosophy, not a pixel-perfect port (complete 2.1–2.8 source prototypes unavailable). This is a custom actor workspace inserted above the native form, not a replacement template; all system editing and drag/drop remain native. Owner-only workspace. GM actions delegate to permission-checked existing panel. Direct activities use the existing combat interaction gate; reaction/context workflows use native sheet. Local order, compact and column preferences are stored by world/user/actor. Linked entities are scene-scoped and revalidated on click. Native containers and the existing identified JJK storage resources are surfaced; no universal CE transfer or supernatural storage is invented. Full drag/reorder of native documents and complete independent sheet templates remain outside this change. Runtime Foundry and multiclient integration testing required.
