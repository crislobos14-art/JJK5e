# Sealed Ink unified interface
Visual default for new clients: sealed. Existing explicitly saved preferences remain intact (choose Sealed Ink in module settings if needed). Native sheet classes still use makeDefault:false to avoid replacing a third-party world sheet; the visual overlay applies to the supported native actor sheets. Native alternative registration retries init/setup/ready separately by actor type; only D&D5e constructors are selected, and GM sees a warning on failure. No mechanics or actor data changed.
Coverage: module panels, builders, rules, character/NPC sheets, progression, supported native combat/item/activity/effect dialogs, JJK journals and packs including translated copies, explicit JJK chat messages and legacy marked cards, module-owned HUD buttons and scoped settings rows. Existing event dock and toasts retain their own surface. Non-JJK chat, unrelated sidebar packs and third-party sheets are not themed. No blanket CSS on body or all Foundry windows. Old unmarked chat messages cannot reliably be classified. Existing JJK dedicated windows already have their original dark CSS even when the optional overlay is disabled.
Style: shared ink/bone/vermilion, violet reserved for CE, gold for GM authority; use bundled JJK Display font, hard corners, fine paper grain, segmented meters, keyboard focus, scoped interaction animations, state change flashes on native actor sheets and JJK panels, reduced-motion and performance options. Legacy perpetual level-up pulse disabled within theme. No new external assets or rules.
Tests: updated visual default assertions, scoped provenance, and late registration regression. Real Foundry UI/versions and visual clipping remain unverified. No release or merge from this branch.
