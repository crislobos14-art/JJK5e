# Sealed Ink — Character Creation Engine (increment 1)
Opt-in enhancement of the existing native creator, not a second actor data model. Open the existing JJK character creator on a character you own and select Sealed Ink for the JJK tools category. The review summarizes real document selections, six ability scores, progress, warnings, and links to the native sheet. The original step controls and advancement manager remain authoritative; closing and reopening reads saved actor state. Point buy is a configurable existing policy, not a mandatory V6 rule. Review does not certify all class/race/feat prerequisites and does not save an all-or-nothing draft. Do not overwrite advanced scores with point buy. Existing creator has incremental writes and existing technique replacement limitations. No release, no version bump. Design follows the attached Sealed Ink philosophy; no third-party assets added.
Validation: seven pure review tests added. Real Foundry 14 / dnd5e 5.3–6.1 interaction and multiclient advancement remain to be tested; CI must run before merge.
